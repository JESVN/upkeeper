# AGENTS.md — Archived Agent Notes

Files here are frozen history. Do not edit, reformat, move, translate, or delete them, and never treat one as the current authority for behaviour.

- An archived note is a pointer to how a decision was reached, which is why active prose may still link into it while [documentation gates](../../../docs/AGENTS.md) skip its contents.
- The only permitted difference from the note as it stood in `implemented/` is the `Archived: YYYY-MM-DD` line below the status.
- When a current rule needs the evidence an archived note holds, link the note from the rule rather than copying its narrative.
