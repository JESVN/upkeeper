# AGENTS.md — Rejected Agent Notes

A rejected note keeps a decision that was considered and declined. It exists only while it prevents a plausible mistake.

- The status line carries the verdict: `Status: rejected — <one-line reason>`. The reason is the fact a reader comes for.
- Delete the note when the idea is no longer tempting, when the constraint that killed it has disappeared, or when a later note supersedes the rejection.
- Do not soften a rejection into a deferral. "Later" with no trigger is a rejection; name the trigger or drop the idea.
