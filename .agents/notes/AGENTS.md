# AGENTS.md — Agent Notes

Agent Notes are decision records: the rationale, alternatives, consequences, and required verification behind a change. Follow the [root instructions](../../AGENTS.md), the [documentation standard](../../docs/AGENTS.md), and the [Agent Note rules](README.md).

**Every new note triggers a supersession check.** Before writing, search the active tree for a note that already covers this decision. If your change reverses or narrows it, decide deliberately: fold the change into the owning note when it is the same decision, or write a new note that cross-links the old one when the decision itself moved. A note in `implemented/` is updated in place for facts — paths, symbols, defaults, stage names — and superseded for decisions.

Never edit anything under [`archived/`](archived/AGENTS.md): those files are frozen history, not current authority.
